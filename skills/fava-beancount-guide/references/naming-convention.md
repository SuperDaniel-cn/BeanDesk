# Beancount 中文科目连字符命名规范

BeanDesk 报表与凭证索引读取 open 指令中声明的完整路径，并提取连字符后的中文部分呈现友好视图。

## 命名格式

根账户:大写英文分类-中文类别:大写英文子级-中文明细

示例：
Assets:Bank-银行存款:Main-XX银行对公户
Expenses:Operations-主营业务成本:Cloud-云计算与算力

## 结构规则

1. 根账户使用 Beancount 规定的 5 类英文：Assets、Liabilities、Equity、Income、Expenses。
2. 根级以下每一级科目，首字符必须使用大写英文字母（段首不可为数字，符合 Beancount 语法与 policy_lint 核查要求），紧接连字符 -，后接中文类别名称（如 Bank-银行存款）。
3. 连字符为科目名称的组成部分。在日记账、凭证页、现金流量表与 BQL 查询中，BeanDesk 会提取多级中文以 · 符号拼接展示（如“银行存款 · XX银行对公户”），且在日记账中悬停可查看完整 Beancount 路径；树形财务报表（资产负债表、利润表、试算平衡表）则按层级树呈现末级中文节点名称（如“XX银行对公户”）。
4. 凭证归档目录与科目名称保持一致，连字符保留在文件夹名称中，对应单一目录层级。

## 格式写法对照

| 格式分类 | 书写示范 | 效果说明 |
| --- | --- | --- |
| 标准规范 | Assets:Bank-银行存款:Main-XX银行对公户 CNY | 满足词法规则，前端提取中文展示，凭证正常穿透 |
| 英文加注释 | Assets:Bank:Checking CNY ; 银行存款 | 行末注释不参与建模，报表界面仅呈现英文 |
| 缺失英文首字母 | Assets:银行存款:基本户 CNY | 词法解析要求每段必须以大写英文字母开头，直接以中文开头会报错 |
