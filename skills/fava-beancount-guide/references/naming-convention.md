# Beancount 中文科目连字符命名规范

BeanDesk 报表与凭证索引读取 open 指令中声明的完整路径，按冒号切分每段并提取每段末尾连字符后的中文部分作为报表标签。

## 命名格式

```
根账户:大写英文分类-中文类别:大写英文子级-中文明细
```

示例：
- Assets:Bank-银行存款:Main-基本户
- Income:Service-主营业务收入:Consulting-架构咨询服务
- Expenses:Operations-管理费用:Rent-办公场地租金

## 结构规则

1. 根账户使用 Beancount 规定的 5 类英文：Assets、Liabilities、Equity、Income、Expenses。
2. 根级以下每一级科目，首字符必须使用大写英文字母（段首不可为数字或汉字，符合 Beancount 词法规则），紧接连字符 -，后接中文名称（连字符后须包含汉字字符）。
3. 连字符为科目名称的组成部分。在日记账、凭证页、现金流量表与 BQL 查询中，BeanDesk 会提取各段最后一个连字符后的中文以“ · ”符号拼接展示（如“银行存款 · 基本户”；若段落中存在多个连字符如 Main-XX银行对公户，取末尾连字符后的“XX银行对公户”）；树形财务报表（资产负债表、利润表、试算平衡表）则按层级树展开，各层级节点（包括父级类别与明细科目）均提取连字符后的中文呈现（如“银行存款”下缩进展开“基本户”）。
4. 凭证归档目录与科目名称保持一致，连字符保留在文件夹名称中，对应单一目录层级。

## 格式写法对照

| 格式分类 | 书写示范 | 效果说明 |
| :--- | :--- | :--- |
| 标准规范 | Assets:Bank-银行存款:Main-基本户 CNY | 满足底层词法规则，前端优雅提取中文展示，凭证正常穿透 |
| 英文加注释 | Assets:Bank:Checking CNY ; 银行存款 | 行末注释不参与系统建模，报表界面仅呈现纯英文 |
| 缺失英文首字母 | Assets:银行存款:基本户 CNY | 词法解析要求每段必须以大写英文字母开头，直接以中文开头会报语法错误 |
