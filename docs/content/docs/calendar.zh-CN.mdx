点击顶栏 日历 打开纳税申报日历界面。在 订阅日历 弹窗中可切换日历来源与获取订阅链接。未连接账本时亦可独立查阅。

## 数据源

系统同一时间支持启用以下来源之一：

- 内置征期日历：预置中国小规模纳税人按季申报的法定征期事项（增值税、企业所得税等）。仅标注法定截止日，遇节假日公休不自动顺延。
- 本地文件：导入本地 `.ics` 日历文件，纯本地读取解析（桌面客户端专属）。
- HTTPS 订阅：支持填入标准日历订阅地址（支持 `https://` 与 `webcal://`，无需公开登录页面；桌面客户端专属）。

## 同步与到期提醒

- 多端同步：点击「复制订阅链接」可获取通用 HTTPS 订阅地址，导入至 iOS、macOS 等支持 iCalendar 协议的系统日历；亦可通过「复制 ICS 内容」或「下载 .ics 文件」进行一次性离线导入。
- 到期提醒：网页端仅支持浏览内置征期日历；桌面客户端运行时，未来 7 天内到期的征期事项将触发应用内提示与系统通知横幅。
