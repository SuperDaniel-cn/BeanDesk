点击顶栏 日历 进入主界面，在右侧 订阅日历 抽屉中管理数据源与订阅。未连接账本时亦可正常浏览。

## 数据源

系统支持启用以下来源之一：

- 内置征期日历：中国小规模纳税人按季申报法定征期（增值税、企业所得税等），仅包含法定截止日，遇节假日不顺延。
- 本地文件：导入本地 `.ics` 文件，仅在本地读取（桌面端可用）。
- HTTPS 订阅：订阅公开或私有日历地址（支持 `https://` 与 `webcal://`；桌面端可用）。

## 订阅与提醒

- 多端同步：点击 复制订阅链接 可将订阅地址导入至 iOS、macOS 或支持 iCalendar 的系统日历；亦可点击 下载 .ics 文件 离线导入。
- 到期提醒：网页端仅支持查看内置征期日历；桌面客户端运行时，未来 7 天内到期事项将触发应用内提示与系统通知横幅。
