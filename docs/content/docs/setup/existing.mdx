## Connect Ledger

In Settings → Ledger Connection, select your ledger folder and click Connect. Configure custom start commands or external services under Advanced Connection.

## Backup Protection

For ledgers not initialized by BeanDesk (lacking a `.beandesk` marker), backup and restore features are disabled to protect existing backup workflows. Initializing over an existing `main.bean` is prohibited.

## Available Features

Once connected, all reporting features are available:
- Financial statements (Trial Balance, Balance Sheet, Income Statement, Cash Flow Statement)
- Journal entries and linked document drilldown
- Native BQL query console
- Tax calendar deadlines
- Local MCP service
