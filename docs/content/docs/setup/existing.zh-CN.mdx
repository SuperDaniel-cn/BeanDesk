## 连接账本

在 设置 → 账本连接 中选择已有账本目录，点击 连接 接入。自定义启动命令或外部服务请在 高级连接 中配置。

## 备份保护限制

未通过 BeanDesk 初始化的既有外部账本（无 `.beandesk` 标识），备份与恢复功能均保持停用，以避免影响原有的备份工作流。系统亦阻止在已有 `main.bean` 的目录上执行初始化。

## 可用功能

连接后可完整使用以下功能：
- 财务报表（试算平衡表、资产负债表、利润表、现金流量表）
- 日记账明细与关联凭证穿透
- BQL 原生查询控制台
- 纳税申报征期日历
- 本地 MCP 服务

参阅 [设置](/zh-CN/desktop) 与 [报表](/zh-CN/reports)。
