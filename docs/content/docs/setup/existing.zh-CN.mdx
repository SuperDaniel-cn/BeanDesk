## 连接已有账本

在 设置 → 账本连接 中指定本地既有账本目录，点击 连接 接入服务。如需通过自定义启动命令运行或直连现有服务地址，可在同一页面中切换连接模式。

## 备份保护限制

为保护已有文件，系统禁止在已存在 `main.bean` 的目录下执行初始化。缺少 `.beandesk` 标记时，备份与恢复面板保持停用。

若要把这本既有账本当标准账本使用（打开备份并补齐 `policies/base`），在账本连接页选择“接管为标准账本”，并在弹窗里显式选择语言包与记账币种（与 MCP 相同）。这只会写入 `.beandesk`、补缺失的 `policies/base` 与备份 gitignore 条目，不改 `data/` 中的分录。本机 MCP 的 `upgrade_ledger` 在确认写入并显式传入 `locale` 后做同样的事。

## 可用功能

连接成功后，可使用以下功能。备份仍须工作目录带有 `.beandesk`（初始化、升级或接管后才会出现）：

- 财务报表：试算平衡表、资产负债表、利润表与现金流量表。
- 日记账与明细穿透：分录检索与关联原始凭证预览。
- BQL 查询控制台：执行原生 Beancount 查询语句。
- 日历：导入一份本机 `.ics`，或订阅一条 HTTPS 日历。
- 本机 MCP 服务：为本地 AI 助手提供账表检索、语法核验（check_ledger）、策略查看与手册查询等工具。

参阅 [设置](/zh-CN/desktop) 与 [报表](/zh-CN/reports)。
