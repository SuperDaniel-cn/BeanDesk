## 1. 选择空目录

在 设置 → 账本连接 中选择一个空文件夹。若文件夹内已存在文件，初始化操作将自动中止以保护数据安全。

## 2. 初始化账本

点击 初始化账本。BeanDesk 将在所选目录中创建标准 Beancount 文件结构（`main.bean`、`config/`、`data/` 与 `documents/`）并写入 `.beandesk` 标识。

后续请在编辑器中编写 `.bean` 文本文件录入账目，BeanDesk 仅提供只读报表核算。

## 3. 连接服务

点击 连接。默认使用内置 Fava 引擎启动或接入本地运行中的 Fava 服务。如需自定义启动命令，可在 高级连接 中配置。

## 4. 配置备份

在 设置 → 数据备份 中配置：

- Git 自动快照：自动检测账本文件（`main.bean`、`config/`、`data/`）变更并生成本地提交，不推送至远程仓库，敏感文件自动忽略。
- 加密增量备份：基于 restic 提供端到端加密备份至本地目录或 S3 兼容存储桶。
  - 立即备份：手动执行一次性归档。
  - 自动备份：账本变动时自动同步至就绪目的地。
  - 保留策略：保留近 48 小时全部快照，此前保留 30 天日快照、12 周周快照、24 个月月快照。数据未变动时不重复记录。

参阅 [设置](/zh-CN/desktop) 与 [报表](/zh-CN/reports)。
