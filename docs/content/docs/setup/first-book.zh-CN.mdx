---
title: 第一本账
description: 在空文件夹中初始化新账本并配置数据备份。
---

## 1. 选择空目录

在 设置 → 账本连接 中指定一个空目录。为防止误覆盖已有数据，若所选目录非空，系统将阻止初始化操作。

## 2. 初始化账本

在桌面端点击“初始化账本”，会弹出语言包与记账币种（默认简体中文 / CNY）。确认后应用在选定目录中建立标准 Beancount 账本骨架（包含 `main.bean`、`config/`、`data/`、`documents/` 与 `policies/base/`）并写入版本化 `.beandesk` 标记。这与 MCP `init_ledger` 相同：必须显式传入 `locale`（`zh-CN` 或 `en`），币种随语言包带入，不能省略。若所选目录是带旧版标记的经营账本，同一页会提供“升级账本骨架”，弹窗同样选择语言包与币种：只补缺失的 `policies/base`，不改 `data/` 中的分录。

后续记账直接使用文本编辑器或外部工具编辑 `data/` 下的月度 `.bean` 文件即可，经营账本负责呈现核算结果。

## 3. 连接服务

在 账本连接 中点击 连接。默认通过内置引擎启动本地服务。若目录仍为空，点“连接”会打开同一语言包弹窗，不会静默写入默认语言包。亦可在该页面切换为外部启动命令或直连已有服务地址。若当前已有连接正在运行，切换模式时将先断开当前连接。

## 4. 配置数据备份

在 设置 → 数据备份 中可配置两套本地备份机制：

- Git 自动快照：实时监控账本核心文件（`main.bean`、`config/`、`data/` 与 `policies/`）。启动监听时自动创建初始快照，后续变动经防抖后自动生成本地提交。快照仅保存在本地仓库，凭证文件与密钥不纳入 Git，亦不推送到任何远程服务器。
- restic 加密备份：端到端加密增量归档至本地文件夹或 S3 兼容对象存储桶，完整覆盖账本、`documents/` 原始凭证与 `policies/`。
  - 口令保护：设置加密密钥需二次确认；密钥遗失将无法解密历史归档。
  - 立即备份：手动执行一次即时增量备份。
  - 自动备份：开启后，账本变动将自动同步写入所有已就绪的目的地。
  - 保留策略：保留最近 48 小时内的全部快照。更早的快照按每天、每周、每月逐渐变稀：保留 30 天的每日快照、12 周的每周快照、24 个月的每月快照。账本无变动时自动跳过，不生成多余快照。

参阅 [设置](/zh-CN/desktop) 与 [报表](/zh-CN/reports)。
