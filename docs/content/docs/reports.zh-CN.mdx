财务报表由经营账本基于当前连接的账本数据实时核算。顶栏的会计期间会同时作用于所有报表、日记账与查询。试算平衡表、资产负债表和利润表可以点科目行进入日记账。

## 试算平衡表

以借贷双栏格式展示各科目的期末余额与层级树状结构，自动校验借贷总额平衡关系；支持按科目名称实时检索过滤。

## 资产负债表

清晰归集资产、负债与所有者权益三大要素，自动核验“资产 = 负债 + 权益”的会计恒等式。当前期间未结转损益自动归入权益分类下的本期损益行次。

## 利润表

按收入与费用要素分类归集营业收入、成本与期间费用，计算当期净利润，并提供上年同期的同比数据（如 2026-03 对比 2025-03，2026-Q2 对比 2025-Q2，2026 对比 2025；当会计期间选择“全部时期”时，不展示对比列）。

## 现金流量表

按直接法分类呈现经营活动、投资活动与筹资活动的现金流入与流出净额，并同样支持上年同期的同比数据呈现（“全部时期”下不展示对比列）；未发生实质资金收付的应计分录自动剔除。

现金流报表通过 Beancount 科目开户指令（`open`）中的元数据完成科目映射：

```beancount
2020-01-01 open Assets:Bank-银行存款:Main-基本户 CNY
  cash: TRUE
2020-01-01 open Income:Service-主营业务收入:Consulting-架构咨询服务 CNY
  cashflow: "sales"
```

- `cash: TRUE`：将科目声明为货币资金账户（如库存现金、银行存款等）。若没有任何科目这样标记，页面提示“未设置资金账户”，而不是显示三个零额。
- `cashflow: "<line>"`：指定该科目在现金流量表中所对应的分类行次。若发生资金变动但对方科目未标记行次，金额将归入未归类项目。
- `cashflow-in` / `cashflow-out`：当同一科目在资金流入与流出时需归入不同分类行次时使用。

标准行次 id，顺序与目录一致：

经营活动：

- 流入：`sales`、`operating-other-in`
- 流出：`purchases`、`wages`、`taxes`、`operating-other-out`

投资活动：

- 流入：`investment-proceeds`、`investment-income`、`asset-disposal`
- 流出：`investment-acquire`、`capex`

筹资活动：

- 流入：`borrowings`、`capital`
- 流出：`debt-principal`、`debt-interest`、`dividends`

初始化时在 `config/accounts.bean` 中预置银行基本户（`cash: TRUE`）与实收资本（`cashflow: "capital"`）的元数据；其余经营科目按 `policies/base/chart-of-accounts.md` 按需开立并配置现金流分类。

## 日记账与凭证穿透

日记账提供按交易对方、摘要、会计要素及业务标签的多维筛选。点凭证列打开明细弹窗，查看分录和关联的发票、回单。加载失败时显示错误提示和重试按钮，而不是空白的账表。

- 凭证关联机制：当 `documents/` 下文件的日期与科目路径与分录行完全匹配，或文件名包含该笔交易的链接标记时，系统将自动建立关联预览。
- 独立凭证库：在凭证页面中集中索引当前会计期间内的全部已归档文件。

## BQL 查询控制台

提供原生 Beancount 查询语言（BQL）交互执行环境，语句直接交由 Fava 引擎执行：

- 内置各月收支汇总、大额费用明细、资金账户余额等常用查询模板。
- 支持使用 Cmd + Enter（macOS）或 Ctrl + Enter（Windows / Linux）快捷键执行查询。
- 查询结果可以列排序，也可以导出 CSV。语句按原文发送。超过 50,000 行时，页面保留前 50,000 行，并提示共返回多少行。
