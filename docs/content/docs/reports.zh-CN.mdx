title: 报表
description: 试算平衡表、三张法定财务报表、日记账与 BQL 查询。
---

财务报表由 BeanDesk 基于当前连接的账本数据实时核算。顶栏的 会计期间（全部时期、年度、季度或月份）为全局时间切片，联动控制所有报表、日记账明细与查询范围。试算平衡表、资产负债表和利润表可以点科目行进入日记账。

## 试算平衡表

以借贷双栏格式展示各科目的期末余额与层级树状结构，自动校验借贷总额平衡关系；支持按科目名称实时检索过滤。

## 资产负债表

清晰归集资产、负债与所有者权益三大要素，自动核验“资产 = 负债 + 权益”的会计恒等式。当前期间未结转损益自动归入权益分类下的本期损益行次。

## 利润表

按收入与费用要素分类归集营业收入、成本与期间费用，计算当期净利润，并提供与上一会计期间的同期对比数据。

## 现金流量表

前端纯函数基于直接法计算，分类呈现经营活动、投资活动与筹资活动的现金流入与流出净额；未发生实质资金收付的应计分录自动剔除。

现金流报表通过 Beancount 科目开户指令（`open`）中的元数据完成科目映射：

```beancount
2020-01-01 open Assets:Bank:Checking CNY
  cash: TRUE
2020-01-01 open Income:Services:Delivery CNY
  cashflow: "sales"
```

- `cash: TRUE`：将科目声明为货币资金账户（如库存现金、银行存款等）。若没有任何科目这样标记，页面显示「未设置资金账户」，不再画出三行零。
- `cashflow: "<line>"`：指定该科目在现金流量表中所对应的法定行次。若发生资金变动但对方科目未标记行次，金额将归入未归类项目。
- `cashflow-in` / `cashflow-out`：当同一科目在资金流入与流出时需归入不同法定行次时使用。

由 BeanDesk 初始化的标准账本已预置主要银行、收入、费用、实收资本及法人垫资科目的元数据标记。

## 日记账与凭证穿透

日记账提供按交易对方、摘要、会计要素及业务标签的多维筛选。点凭证列打开明细弹窗，查看分录和关联的发票、回单。加载失败时显示错误和重试，而不是一本空账。

- 凭证关联机制：当 `documents/` 下文件的日期与科目路径与分录行完全匹配，或文件名包含交易的唯一链接标识时，系统将自动建立关联预览。
- 独立凭证库：在凭证页面中集中索引当前会计期间内的全部已归档文件。

## BQL 查询控制台

提供原生 Beancount 查询语言（BQL）交互执行环境，语句直接交由 Fava 引擎执行：

- 内置各月收支汇总、大额费用明细、资金账户余额等常用查询模板。
- 支持使用 Cmd + Enter（macOS）或 Ctrl + Enter（Windows / Linux）快捷键执行查询。
- 查询结果可以列排序，也可以导出 CSV。语句按原文发送。超过 50,000 行时，页面保留前 50,000 行，并写明一共返回了多少行。
