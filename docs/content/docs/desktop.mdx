## Ledger Connection

Choose a connection mode under Service Status. The three modes are exclusive and share one log. Switching while connected or still starting asks first. Confirming disconnects the current session and leaves you on the new panel. It does not connect the new mode for you.

- Bundled Engine: Choose a ledger directory and, in an empty folder, initialize it. Connect starts the bundled engine. A saved start command stays on file and is not run.
- External Command: Same directory, plus a start command and a local address. The command is passed to the shell unchanged. The port is probed first; if Fava is already there, BeanDesk attaches.
- Direct Address: A service URL only. No process is started.

Stop ends a process this window started. Disconnecting a direct address leaves the other service running.

## Settings Tabs

- General: Language, theme, and local MCP configuration.
- Ledger Connection: Bundled engine, external command, or direct address.
- Backup: Git Auto-Snapshot and restic encrypted backups (available for BeanDesk-initialized ledgers; see [First book](/setup/first-book)).

## Connection Logs

Connection events are recorded to local log files (10 MB cap with rolling eviction). Clear resets only the on-screen log view.

## Software Updates

The desktop application includes automated update checks for macOS, Windows, and Linux.

## Tray

Closing the main window hides BeanDesk to the tray. Click the tray icon or Show to bring the window back. Quit from the tray ends the app and stops a Fava process this window started.
