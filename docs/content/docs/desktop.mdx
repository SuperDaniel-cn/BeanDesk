## Ledger Connection Modes

Settings provides three mutually exclusive connection modes, sharing a unified activity log:

- Bundled Engine: Specify your ledger working directory to launch via the bundled standalone engine, requiring no Python environment or manual commands. Empty folders can be initialized here directly. The local address defaults to `http://127.0.0.1:5000`; you can change the loopback port.
- External Command: Specify a directory, start command, and local origin. Probes the port first, attaching directly if a local Fava service is already running; otherwise spawns the command in an isolated process group.
- Direct Address: Provide an existing Fava service URL (local or remote) without managing background processes.

If a session is active, switching modes requires confirmation and disconnects the active session first. Clicking Stop terminates only the process group launched by the current window, leaving external services intact.

## Settings Tabs

- General: Language preference, appearance theme (light, dark, or system), and local MCP configuration.
- Ledger Connection: Working directory picker, connection mode switcher, and supervision controls.
- Backup: Local Git snapshots and restic encrypted backups (available for BeanDesk-initialized ledgers; see [First book](/setup/first-book)).
- About: App name, software updates, and license.

## Connection Logs

Connection events are recorded to local log files (10 MB cap with rolling eviction). Clear resets only the on-screen log view without affecting disk logs.

## Handbook Window

Clicking the book icon in the header opens this manual in a dedicated, distraction-free secondary window. The window remains warm in memory; closing it merely hides it for instant re-invocation.

## System Tray and Background Presence

Closing the main or handbook window hides the application to the system tray while keeping background processes and watch listeners active. Click the tray icon or choose Show to focus the main window. Choosing Quit from the tray exits the application completely and terminates any Fava process group started by this window. Launching the desktop app again brings the running instance to the foreground.

## Software Updates

Check for updates from Settings → About. Available on macOS, Windows, and Linux.
