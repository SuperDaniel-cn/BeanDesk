BeanDesk can operate as a standard stdio MCP server. In Settings → General, click Copy Config to integrate with Cursor, Claude Desktop, or other MCP hosts.

## Operating Principles

- Shared Configuration: Automatically resolves the working directory and active Fava address configured in Settings.
- Read-Only: Forwards read-only requests. If the service is offline, ledger tools return an error without spawning processes.
- Ledger Entries: Recording and updating transactions is performed directly by the agent on monthly text files; MCP does not forward entry write endpoints.

## Tool Capabilities

- Ledger Capabilities: Provides working directory resolution, read-only financial reports, native BQL queries, document listing, and syntax checking; can initialize a ledger skeleton upon explicit confirmation, but does not provide entry write endpoints or process management.
- Handbook Integration: Agents can invoke `get_handbook` to read this documentation offline without requiring a running Fava engine.
- Data Boundary: Does not expose backup credentials, document file contents, or private calendar subscription URLs.
