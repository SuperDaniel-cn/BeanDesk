## 账本连接模式

在设置页中可选择三种互斥的连接方式，连接日志统一记录：

- 内置引擎：指定账套工作目录，由应用随附的独立引擎直接加载，无需配置 Python 环境或命令行。空目录须通过会计准则与记账币种弹窗初始化（“初始化企业账套”，或对空目录点“连接”）。连接本身不会静默写入会计准则。本机地址默认为 `http://127.0.0.1:5000`，可改为其他回环端口。
- 外部命令：指定工作目录、启动命令与本地服务地址。启动时优先探测目标端口，若已有运行中的 Fava 服务则直接接入；未运行时则在独立进程组中执行启动命令。
- 地址直连：仅填写运行中的 Fava 根地址（如局域网或远程服务器），纯 HTTP 连接，不在本地启动任何进程。

若当前连接处于运行或启动状态，切换模式需先确认断开当前会话。点击“停止”仅终止由当前窗口拉起的进程组，不会干扰外部已存在的服务。

## 设置分组

- 常规设置：界面语言偏好、外观主题（浅色/深色/跟随系统）与本地 MCP 服务集成配置。
- 账本连接：工作目录选择、连接模式切换、服务看管控制台，以及“更改会计准则”（同时写入 `.beandesk` 与 `policies/base/rules.toml`，已审核批准的自定义规则会保留）。
- 数据备份：本地 Git 快照与 restic 加密备份（初始化、升级或接管为标准账套后可用，详见 [第一本账](/zh-CN/setup/first-book) 与 [已有 Beancount](/zh-CN/setup/existing)）。从 BeanDesk 恢复账套不会带回本机 `policy.json`，需要在主窗口重新审核批准或恢复上次批准的版本。
- 关于：应用名称、版本更新与许可证。

## 连接日志

连接与服务事件会自动追加至本地日志文件（单文件上限 10MB，超出后从最早的记录开始丢弃）。界面中的“清除”操作仅清空当前窗口的显示记录，不影响本机日志文件。

内置引擎的运行输出也会写入同一日志文件。

## 用户手册与独立窗口

点击顶栏的手册图标将在独立的无干扰窗口中打开本手册。手册窗口保持常驻；关闭时只隐藏，再次打开可立即显示。

## 系统托盘与常驻机制

关闭主窗口或手册窗口时，应用会隐藏到系统托盘并继续在后台运行。点击托盘图标或菜单中的“显示”即可将主窗口唤至前台。在托盘菜单中选择“退出”将完整退出应用，并终止本次由当前窗口拉起的服务进程。若再次启动应用，系统会自动激活已在运行的实例窗口。

## 版本更新

桌面端可在 设置 → 关于 中查看版本并检查更新，覆盖 macOS、Windows 与 Linux 平台。
