## 账本连接

服务状态下面选择连接方式。三项互斥，日志共用。已经连上或正在启动时，切换会先确认；确认后断开当前会话，停在新的面板上，不会自动连上。

- 内置引擎：选择账本目录，可在空文件夹里初始化。连接时走随包装的引擎。已保存的启动命令留着，这次不执行。
- 外部命令：同一账本目录，另填启动命令和本机地址。命令原样交给 shell。启动前先探测端口，端口上已是 Fava 则直接接入。
- 地址直连：只填服务地址，不启动进程。

停止只终止本窗口拉起的进程。地址直连的断开不会停掉对方的服务。

## 设置分组

- 常规设置：界面语言、外观主题与本地 MCP 服务配置。
- 账本连接：内置引擎、外部命令与地址直连。
- 数据备份：Git 自动快照与 restic 加密备份（仅支持由 BeanDesk 初始化的账本，详见 [第一本账](/zh-CN/setup/first-book)）。

## 连接日志

连接记录自动保存至本地文件（单文件上限 10MB，滚动覆盖）。界面上的清除按钮仅重置当前窗口显示。

## 版本更新

桌面客户端支持自动检查更新，提供 macOS、Windows 与 Linux 安装包。

## 托盘

关闭主窗口会隐藏到托盘。点击托盘图标或「显示」回到主窗口。托盘里的「退出」才结束应用，并停掉本窗口拉起的 Fava。
