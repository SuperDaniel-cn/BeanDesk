## 账本连接

- 账本目录：选择本地账本所在文件夹。
- 初始化账本：在空文件夹中建立标准 Beancount 骨架。
- 连接 / 停止：通过内置引擎启动或接入服务。停止操作仅终止由当前窗口拉起的托管进程。

## 高级连接

- 本机服务：指定本地启动命令（如 `fava --host 127.0.0.1 --port 5000 main.bean`）。启动前先探测端口，若已运行 Fava 服务则直接接入。
- 外部服务：直接填写运行中的 Fava 服务地址（如 `http://127.0.0.1:5000`）。

## 设置分组

- 常规设置：界面语言、外观主题与本地 MCP 服务配置。
- 账本连接：本地工作目录选择与内置引擎连接。
- 高级连接：自定义启动命令与远程服务连接。
- 数据备份：Git 自动快照与 restic 加密备份（仅支持由 BeanDesk 初始化的账本，详见 [第一本账](/zh-CN/setup/first-book)）。

## 连接日志

连接记录自动保存至本地文件（单文件上限 10MB，滚动覆盖）。界面上的清除按钮仅重置当前窗口显示。

## 版本更新

桌面客户端支持自动检查更新，提供 macOS、Windows 与 Linux 安装包。

## 托盘

关闭主窗口会隐藏到托盘。点击托盘图标或「显示」回到主窗口。托盘里的「退出」才结束应用，并停掉本窗口拉起的 Fava。
