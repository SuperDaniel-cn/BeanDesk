---
title: 概述
description: BeanDesk 记账工作台功能概览与手册导航。
---

BeanDesk 是一款本地优先的复式记账工作台，直连本地账本目录与 Fava 引擎，无需自建后端或云端账号。

<Cards>
  <Card title="第一本账" href="/zh-CN/setup/first-book">
    在空文件夹建立新账本骨架并启用数据备份。
  </Card>
  <Card title="已有 Beancount" href="/zh-CN/setup/existing">
    直接连接既有 Beancount 账本目录查看财务报表。
  </Card>
  <Card title="报表" href="/zh-CN/reports">
    查看试算平衡表、资产负债表、利润表与现金流量表。
  </Card>
  <Card title="设置" href="/zh-CN/desktop">
    管理本地服务连接、进程看管、Git 快照与 restic 加密备份。
  </Card>
  <Card title="日历" href="/zh-CN/calendar">
    导入本机日历，或订阅一条 HTTPS 日历。
  </Card>
  <Card title="本机 MCP" href="/zh-CN/mcp">
    为本地 AI Agent 提供只读账本与离线手册检索工具。
  </Card>
</Cards>
