---
title: 概述
description: BeanDesk（经营账本）一人公司对公财税与合规工作台功能概览与手册导航。
---

BeanDesk（经营账本）是一款面向一人有限责任公司、独立创作者与微型团队的本地优先财务工作台。直连本地账本目录与 Fava 引擎，无需自建后端或云端账号。

  </Card>
  <Card title="已有 Beancount" href="/zh-CN/setup/existing">
    直接连接既有 Beancount 账本目录查看财务报表。
  </Card>
  <Card title="报表" href="/zh-CN/reports">
    查看试算平衡表、资产负债表、利润表与现金流量表。
  </Card>
  <Card title="记账与凭证" href="/zh-CN/bookkeeping">
    账本目录、凭证命名与一人公司分录约定。
  </Card>
  <Card title="设置" href="/zh-CN/desktop">
    管理本地服务连接、进程看管、Git 快照与 restic 加密备份。

  </Card>
