title: 本机 MCP
description: 通过 Model Context Protocol 为本地 AI Agent 提供只读账本与手册查询能力。
---

BeanDesk 支持作为标准 stdio MCP 服务运行。在 设置 → 常规设置 点击 复制配置，即可将命令配置集成至 Cursor、Claude Desktop 等客户端。

## 运行约定

- 共享配置：自动读取桌面设置中的工作目录与活动 Fava 服务地址，无需在提示词中手动指定路径。
- 只读查询：仅转发只读请求。若底层服务未运行，账本查询工具返回错误提示，不会在后台启动进程。
- 分录修改：记账与修改分录由 Agent 直接编辑工作目录中的月度文本文件，MCP 不转发分录写入接口。

## 工具能力

- 账本服务：提供工作目录检测、只读账表与原生 BQL 查询、单据目录检索与账本语法校验；支持在明确确认后初始化账本骨架，但不开放分录写入或底层进程控制。
- 手册查询：支持通过 `get_handbook` 工具离线读取本手册内容，无需连接 Fava 服务。
- 安全边界：不暴露备份密钥、凭证文件内容或私有日历订阅地址。
