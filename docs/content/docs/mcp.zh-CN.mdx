---
title: 本机 MCP
description: 通过 Model Context Protocol 为本地 AI Agent 提供只读账本与手册查询能力。
---

经营账本支持作为标准 stdio MCP 服务运行。在 设置 → 常规设置 中点击“复制配置”，即可将命令配置集成到 Cursor、Claude Desktop 等能写工作目录的本机客户端。不能把任意云端聊天窗口丢图当成记账路径。

## 运行约定

- 共享配置：自动复用桌面设置中保存的当前账本工作目录与活动 Fava 服务地址，无需在 AI 提示词中手动指定路径。
- 只读转发：账本查询工具仅转发只读请求。若底层服务未运行，工具将返回未就绪提示，不会在后台静默拉起进程。
- 分录编辑：记账与凭证录入由能写工作目录的本机 Agent 编辑月度 `.bean` 文件，MCP 不转发通用分录写入接口。
- 本机与云端：云端模型会把对话里的单据送出本机。只有本机模型和本机写盘同时成立时，单据才可以不经过模型厂商。

## 工具能力

- 账本服务：提供工作目录身份识别、只读财务报表与原生 BQL 查询、单据目录检索与账本语法校验；支持在收到明确写入确认（`confirmWrite`）后初始化空账本骨架，可选 `locale`（省略为 `zh-CN`，`en` 为美元英文骨架），但不开放分录写入或底层进程控制。`check_ledger` 会先执行 `bean-check`；若 `policies/` 下存在 TOML 规则，再按生效区间核验。校验通过仅表示格式与规则匹配，不构成法定税务鉴定。
- 离线手册：`get_handbook` 提供随包装的产品功能与使用手册（界面导航、数据备份、日历订阅与报表分析），无需连接网络即可离线检索。可选 `locale`：`zh-CN` 或 `en`（省略或未识别语言时回退为 `en`）。
- 工作目录策略：`list_policies` 与 `get_policy` 用于检索并阅读当前工作目录 `policies/`（包含初始化生成的 `base/` 基线）下的业务制度与记账规范；自动化 TOML 规则由 `check_ledger` 统一核验执行，不作为文本内容输出。
- 安全边界：严格限制数据暴露范围，不向外部助手输出备份密钥、凭证文件原始字节或私有日历订阅地址。
