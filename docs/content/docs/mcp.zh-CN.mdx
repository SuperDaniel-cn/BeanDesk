---
title: 本机 MCP
description: 通过 Model Context Protocol 为本地 AI Agent 提供只读账套与手册查询能力。
---

BeanDesk 支持作为标准 stdio MCP 服务运行。在 设置 → 常规设置 中点击“复制配置”，即可将命令配置集成到 Cursor、Claude Desktop 等能写工作目录的本机客户端。只有能写入工作目录的本地客户端才能记账；仅能接收图片的云端聊天窗口不行。

## 运行约定

- 共享配置：自动复用桌面设置中保存的当前账套工作目录与活动 Fava 服务地址，无需在 AI 提示词中手动指定路径。
- 卡片语言：`displayBlock` 跟随账套已启用的会计准则（`zh-CN` 或 `en`）。`init_ledger` / `upgrade_ledger` 用请求里的 `locale`；没有标记或未就绪的国家码用英文，不读操作系统语言。`get_handbook` 仍用自己的 `locale`。
- 只读转发：账套查询工具仅转发只读请求。若底层服务未运行，工具将返回未就绪提示，不会在后台静默拉起进程。
- 分录编辑：记账与凭证录入由能写工作目录的本机 Agent 编辑月度 `.bean` 文件，MCP 不转发通用分录写入接口。
- 本机与云端：云端模型会把对话里的凭证送出本机。只有本机模型和本机写盘同时成立时，原始凭证才可以不经过模型厂商。

## 工具能力

- 账套服务：提供工作目录身份识别、只读财务报表与原生 BQL 查询、原始凭证目录检索与语法校验；支持在收到明确写入确认（`confirmWrite`）后初始化标准账套结构。`locale` 必填：`zh-CN`（人民币中文）或 `en`（美元英文），不能省略，也不根据操作系统语言猜测。各国代码已在参数表中预留，尚未合并的会报未就绪。`upgrade_ledger` 使用同样的写入确认与 `locale`，把既有 Beancount 账本接管为标准账套，或升级旧版账套结构：只补缺失的 `policies/base`，不改 `data/` 分录。不开放分录写入或底层进程控制。`check_ledger` 会先执行 `bean-check`，再执行随包装会计准则与本机上次审核批准的自定义 TOML（不信任磁盘上未批准的文件）。MCP 可通过 `init_ledger` / `upgrade_ledger` 播种，但不能审核批准、回滚或更改会计准则。校验通过仅表示格式与规则匹配，不构成法定税务鉴定。
- 离线手册：`get_handbook` 提供随包装的产品功能与使用手册（界面导航、数据备份、日历订阅与报表分析），无需连接网络即可离线检索。可选 `locale`：`zh-CN` 或 `en`（省略或未识别语言时回退为 `en`）。
- 工作目录策略：`list_policies` 与 `get_policy` 用于检索并阅读当前工作目录 `policies/`（包含初始化生成的 `base/` 基线）下的业务制度与记账规范；自动化 TOML 规则由 `check_ledger` 统一核验执行，不作为文本内容输出。
- 安全边界：严格限制数据暴露范围，不向外部助手输出加密口令、凭证文件原始字节或私有日历订阅地址。
