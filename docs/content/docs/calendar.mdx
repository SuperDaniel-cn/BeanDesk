---
title: Calendar
description: A month grid for one imported or subscribed calendar.
---

Open Calendar in the top bar. It works without a ledger connection. BeanDesk does not ship a calendar of its own.

## Sources

One source is active at a time, and only in the desktop app:

- Local file: import an `.ics` file. It is read on this computer.
- HTTPS subscription: paste an `https://` or `webcal://` address. `webcal://` is stored as `https://`.

## Sync and notices

- Copy subscription URL copies that HTTPS address for a phone or another calendar app. Copy ICS content and Download .ics file export the calendar that is currently loaded.
- While the desktop app is running, an event due within 7 days shows one in-app notice and one system banner. The browser does not load a calendar.
