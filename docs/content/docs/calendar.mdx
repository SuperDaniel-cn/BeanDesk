Open Calendar in the top bar and manage data sources in the Subscribe to Calendar dialog. Available even without an active ledger connection.

## Calendar Sources

Select one active calendar source:

- Bundled Tax Calendar: Preconfigured quarterly filing deadlines for small-scale taxpayers in China. Public deadlines only; dates are not shifted for holidays.
- Local File: Import a local `.ics` file, processed strictly on this machine (Desktop only).
- HTTPS Subscription: Subscribe to standard calendar feeds (supports `https://` and `webcal://`; Desktop only).

## Subscriptions and Reminders

- Sync: Click Copy subscription URL to import into iOS, macOS, or any iCalendar client, or Download .ics file for a one-time import.
- Notifications: The web browser displays the bundled tax calendar only; while the desktop application is running, events due within 7 days trigger an in-app notice and an OS desktop notification banner.
